# Project Rules (`pi-sect`)

## GitHub Deployment Rule
- **Always Push Changes to GitHub**: Whenever any code, configuration, or documentation changes are made in this repository, you MUST stage, commit, and push them to GitHub (`git push origin main`) before concluding your task so the user can immediately view and test the live updates in the browser (`https://talsheaffer.github.io/pi-sect/`).
- Verify `git status` is clean and the push to `origin` succeeded after every change.
